# 🚀 AstraLang

AstraLang is a simple programming language project built from scratch.

The purpose of AstraLang is to learn and understand how a programming language works internally, starting from reading source code, processing instructions, and executing programs through a custom runtime system.

AstraLang is not designed to replace professional programming languages like Python, C++, Rust, or Java. This project is created for learning, experimenting, and exploring how compilers, parsers, and runtimes work behind the scenes.

---

# ✨ Features

- Custom parser system
- Custom runtime engine
- Simple programming syntax
- Lightweight architecture
- Beginner friendly code structure
- Built from zero for educational purposes

# 🧠 How AstraLang Works

AstraLang uses a simple programming language workflow:

```
User Code (.as)
        |
        v
     Parser
        |
        v
 Instructions
        |
        v
     Runtime
        |
        v
     Output
```

The process:

1. User writes a program using AstraLang syntax.
2. Parser reads the source code.
3. Parser analyzes and converts the code into instructions.
4. Runtime executes those instructions.
5. The program produces an output.

# ⬇️ Download AstraLang

Clone this repository:

```bash
git clone git@github.com:JANUARPROGRAM/Achmas-Januar.git
```

Enter the folder:

```bash
cd Achmas-Januar
```

Check files:

```bash
ls
```

You should see:

```
parser.py
runtime.py
tes.as
README.md
```

---

# ▶️ Running AstraLang

Run the runtime system:

```bash
python runtime.py
```

or:

```bash
python3 runtime.py
```
